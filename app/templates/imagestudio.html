To enable the Image Studio embed, set the SWARMUI_EXTERNAL_URL environment variable to the public URL of your SwarmUI instance (the address your browser can reach it at).

SwarmUI is already running in the same Docker stack on port 7801 — set the env var to your host's IP or hostname:

SWARMUI_EXTERNAL_URL=http://<your-truenas-ip>:7801

For TrueNAS, edit truenas-compose.yml and set the value under the world service's environment section, then redeploy.

You can still generate images using the AI + Image Gen tab — it talks directly to SwarmUI internally without needing this URL.
