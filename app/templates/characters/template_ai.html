How this works

1. Give it the rules — upload a rulebook (PDF / Markdown / TXT / JSON), paste the character-creation chapters, or use this world's own rules. A long book is read in pieces; only the parts about what a sheet tracks matter.

2. Review the draft — the AI proposes the fields and the integration: which resource is the HP track, which number is XP, which fields are the character's name and player, the status conditions, what a Short/Long Rest refills, the sheet pages, how the party roster compares characters, and a rules digest the other AI tools use. Anything it got wrong is dropped before you see it.

3. Create, then fine-tune in the normal template editor. Nothing is saved until you press Create — and a template made this way works exactly like a hand-made one.
