This page can embed a live, self-hosted session running the real NeonDragonsEditor desktop app, so a GM can build races/professions/feats/items from any browser without installing Python/Qt locally. It's an optional add-on with no precedent in this project — see docs/DEPLOYMENT.md before enabling it, and expect to need some iteration to get it running well.

To enable it: start the editor Compose profile (with the content repo mounted into its volume), then set the EDITOR_EXTERNAL_URL environment variable (or the field below) to the public URL of its noVNC viewer:

EDITOR_EXTERNAL_URL=http://<your-server-ip>:6081

For TrueNAS, edit truenas-compose.yml and set the value under the world service's environment section, then redeploy. This can also be set per-instance under Settings → System, which takes priority over the environment variable.
