Cheatsheet — Markdown superpowers
  • :::tip, :::note, :::warning, :::danger, :::lore, :::collapse, :::gm — a themed block, closed by a line containing only ::: (an optional title goes on the first line: :::tip Read this first). :::gm blocks are removed from the page for players entirely; :::collapse renders a click-to-open section (default title "Details").
  • ```statblock fence — the first line is the block's name, following Label: value lines become rows (split on the first colon), other lines render as free text; a 📋 Copy button copies the raw text.
  • Unknown :::type names still render (as a note callout titled with the type name) — content is never silently dropped.
  • rules.json overlay keys: sections maps a heading slug (the part after # in a TOC link) to {"icon", "title", "players_visible", "order"}; tabs is a list of {"id", "label", "sections": [slugs]} — listed slugs show in that order, unlisted sections land in a trailing "More" tab; players_visible: false hides the section from players (GMs still see it).
