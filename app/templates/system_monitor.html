Fans

The ticked fans speed up as the GPU heats up (the BIOS curve cannot see the GPU die). They speed up at once and slow down gently. Never below 20 %; if the GPU temperature cannot be read, or it is at the panic temperature, they go to 100 %. Run Check on a fan first: an output whose rpm falls when asked for more must not be used.

Speeds are held by this app. If it stops cleanly, any fan it holds is raised to at least 60 % so a GPU used by another container is not left without air; if it is killed, the fan stays at its last value. BIOS puts a fan back exactly as the BIOS had it, and a reboot gives every fan back.
