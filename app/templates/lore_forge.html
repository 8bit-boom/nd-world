🔥 Lore Forge

Fine-tune a small model on {{ world.name if world else 'this world' }}'s lore — the ND Lore Forge trainer (Llm-training), installed inside nd-world itself. One click installs it, one click removes it. The trained model is pushed into Ollama and/or the Studio hub, and nd-world's chat can switch to it.

GM secrets are included in what the model learns: training happens locally on this machine and the trained model is GM-trusted, exactly like the training bundle. Players never see this page or the model settings.

📦 The trainer

Not installed. Install downloads the trainer's worker code (a few MB) from GitHub; Set up the training environment then installs Python, PyTorch and Unsloth into its own venv — that one is a multi-GB download and runs as a background job you can cancel.
