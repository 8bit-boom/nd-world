Spoken language

    

      Pin the language spoken at the table for every session-recording transcription (background jobs, one-shot upload, and live recording). Auto-detect works for most single-language sessions, but pinning is faster and avoids the garbled, repeating-phrase transcripts Whisper can produce when it misjudges the language. One-off chat attachments don't use this.
    

    
    

      
      
    

  

  

    
Name glossary

    

      Campaign NPC names, places, and invented terms — hinted to Whisper on every session-recording transcription (background jobs, one-shot upload, and live recording) so it doesn't autocorrect them to real words. One-off chat attachments don't use this. Comma or newline separated.
      World entity names (characters, creatures, locations, organizations, races, professions — up to 50) are automatically added on top of whatever you type here, so you don't have to keep this list in sync by hand.
    

    
    

      
      
      
    

  

  

    
Speech enhancement

    

      Run a real ML denoising model (DeepFilterNet) over every session-recording audio file before it reaches Whisper — meaningfully better against sustained background noise (music, hum, HVAC) than a browser's own echo-cancellation/noise-gate alone (see the mic recorder's built-in suppression, always on). Applies to background jobs, one-shot upload, and live recording. One-off chat attachments don't use this.
    

    

      Not installed on this server — see docs/DEPLOYMENT.md for how to build the image with speech enhancement enabled.
    

    
    

      
    

  

  

    
Recap instructions

    

      Extra steering for the AI-written recap itself (not transcription) — e.g. "Write summaries in Spanish", "Use a dry, sarcastic tone", "Focus only on combat". Applied to every session-recording recap (background jobs, one-shot upload, and re-summarize).
