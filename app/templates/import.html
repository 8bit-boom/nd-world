📥 Import

Paste or upload a JSON file. It'll figure out what kind of content it is — schematic elements, entities, player characters, stat-block/sheet templates, random tables, map markers, or world rules — and import it accordingly. To import several different kinds of things at once, wrap them in {"imports": [...]} — each entry can be a bare blob (auto-detected) or an explicit {"kind","data","params"} for kinds that need extra details.

📦 Bulk JSON Import

Select several JSON files at once — each is analyzed the same way as the single-file box above and imported automatically if nothing more than that file's own content is needed. Files that need extra details (which map or schematic to attach to, a stat-block template's kind) aren't guessable in bulk — those get flagged below to import one at a time above instead.

🖼 Bulk Image Import

Select several portrait/art files at once — each one is matched to an entity in this world by filename (e.g. "Gandalf.png" → the entity named "Gandalf"). Review the matches below and adjust any before importing; files left on "— Skip —" aren't uploaded at all.

🔄 Bulk Image Format Conversion

Re-encode every image already in this world — entity/character art, portraits, schematic backgrounds and embedded images, investigation board cards, and uploaded maps — to a single format and quality. Useful for shrinking a world full of large PNGs down to AVIF/WebP, or converting to PNG/JPG for compatibility elsewhere. Runs in place; every reference is updated automatically.
