This page can embed a live, self-hosted Android session running the real NeonDragonsApp, so it can be opened from a browser with nothing installed. It's an optional, resource-heavy add-on — see docs/DEPLOYMENT.md for host requirements before enabling it.

To enable it: start the android Compose profile, then set the ANDROID_EMULATOR_URL environment variable (or the field below) to the public URL of its noVNC viewer:

ANDROID_EMULATOR_URL=http://<your-server-ip>:6080

For TrueNAS, edit truenas-compose.yml and set the value under the world service's environment section, then redeploy. This can also be set per-instance under Settings → System, which takes priority over the environment variable.
