# Fixtures

`dungeondraft-1.0.1.3-sample.uvtt.json` is a **real Universal VTT export** (format 0.3, written by Dungeondraft 1.0.1.3), copied from
`exampleMaps/sampleMap.dd2vtt` in <https://github.com/Imagix/uvtt2fgu> with one change: the embedded 2560 x 2560 PNG (2.8 MB) is
left out (`"image": ""`). Everything else is as exported: `map_origin` (2, 1), a 10 x 10 square map at 256 pixels per square, 4
`line_of_sight` polylines, 1 `objects_line_of_sight` outline, 2 portals (one closed door, one open window) and 2 lights.
