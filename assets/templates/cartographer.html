Paint battle maps and generate dungeons and worlds. The studio is built into nd-world — no separate install; projects are kept in {{ cartographer.dir }}/data.

Full Backup includes Map Maker project files, playable schematics and their links. Restore replaces or merges the project folder and database associations as one Full Backup.

Existing maps and schematics open in their original editors. Copy to Map Maker creates a separate project with the background, image-map pins and regions, or schematic floors, walls, lights, visible pins, visible tokens, floor links and solid lines and pencil paths. Lines and paths become approximate paint strokes: their width, ends and stacking can differ. Visible token names become informational Map Maker markers, not playable combat tokens. Hidden elements, dashed lines, entity links, fog, combat, and other gameplay data stay in the original unless a separate playable copy is linked. Character travel still uses the original map unless a linked playable floor group is created. Changes to copies are independent. Republishing a Map Maker project can replace a schematic's manually edited elements, including tokens.

Create playable copy makes a new schematic from the current floor's player-filtered picture, walls and lights. Inspect the picture before showing it to players. Tokens and floor travel can be added in its editor. Artwork refresh replaces only that copy's picture; walls and lights refresh is separate and only succeeds while neither has been changed in the playable copy. Both refuse a changed background, size or grid. Tokens, fog and other gameplay data stay unchanged.

Create linked playable floors prepares copies of every floor and connects its Map Maker stairs for character travel. Existing playable copies must have matching artwork. If linking fails, any copies already created remain in Maps; inspect them before retrying.

Update playable scene inspects all linked floors, previews available artwork and geometry updates, and refuses to overwrite playable-side wall or light edits. Tokens, fog, combat and character positions remain intact.

Build → Prepare → Run: Build paints or copies a map, Prepare creates and updates linked playable floors, and Run opens the live scene or starts its combat from encounters and loot.
